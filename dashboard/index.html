THEORETICAL BOUNDARY
⚖️

Fundamental Impossibility Theorem (Cover & Thomas; Garg et al.)

When observable feature samples X are strictly identical and frozen model parameters θ remain constant, any label-free monitor is a deterministic function f(X, θ). It is mathematically impossible for any label-free monitor to distinguish between stationary performance and a 56% collapse in accuracy without access to deployment ground-truth labels.

🏆 Proven Findings

  • COTT Significantly Defeats Confidence Proxies: COTT yields statistically lower error than CBPE, ATC, DoC, and AC across all 51 windows (all FDR-adjusted p ≤ 0.0084).
  • Block Length Invariance: Sensitivity analysis across block sizes b ∈ {2, 3, 5, 8} proves significance is not an artifact of autocorrelation windowing.
  • ATC Fractional Tie-Weighting: Prevents calibration step plateaus from inflating estimates on discrete probability outputs.

⚠️ Documented Limitations

  • Scalar OT vs COTT Equivalence: Published COTT does not demonstrate statistically significant superiority over 1D scalar OT (p = 0.5157; 95% CI covers zero [-0.0247, +0.0521]).
  • Single-Stream Generalizability: Electricity is a single temporal dataset. Cross-domain generalizability requires TableShift and CIC-IDS benchmarks.
